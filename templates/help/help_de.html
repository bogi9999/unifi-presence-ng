Unifi-Presence NG meldet die Anwesenheit ausgewählter UniFi-Clients per MQTT (Topic <Topic>/<Gerätename>, JSON mit connected, ssid, signalDbm, ap …) sowie Sammelwerte wie „jemand zu Hause“ und Gruppen.

Unterstützt UniFi-OS-Konsolen (Port 443), UniFi OS Server (Port 11443) und die klassische Network Application (Port 8443) – inkl. Network 9.x, 10.x und 11.x. Kein Express-Server und kein Node.js nötig.

Empfehlung: lokalen UniFi-Benutzer ohne 2FA anlegen (Rolle „Nur anzeigen“ für Network genügt).
