Unifi-Presence NG reports the presence of selected UniFi clients via MQTT (topic <topic>/<device name>, JSON with connected, ssid, signalDbm, ap …) plus summary values such as “anyone home” and groups.

Supports UniFi OS consoles (port 443), UniFi OS Server (port 11443) and the classic Network Application (port 8443) – including Network 9.x, 10.x and 11.x. No Express server and no Node.js required.

Recommendation: create a local UniFi user without 2FA (the “View only” role for Network is sufficient).

Documentation: LoxBerry wiki
